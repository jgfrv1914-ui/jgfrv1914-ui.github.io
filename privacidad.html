Política de privacidad

"Datos Curiosos Shorts" es una herramienta personal de automatización creada y operada por una sola persona para generar y publicar videos en su propio canal de YouTube.

La aplicación usa la YouTube Data API únicamente para subir videos a la cuenta de YouTube de su propio autor. No accede a datos de otros usuarios, no comparte información con terceros y no recolecta datos personales de nadie más.

La aplicación también usa la API de TikTok (Login Kit y Content Posting API, permisos user.info.basic y video.publish) únicamente para identificar la cuenta de TikTok de su propio autor y publicar videos en ella. No accede a datos de otros usuarios de TikTok.

Las credenciales de acceso (tokens de OAuth) se almacenan de forma cifrada como secretos en GitHub Actions y no se comparten ni se publican.
